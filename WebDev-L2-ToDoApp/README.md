## 📝 To-Do Web App

A simple, modern, and responsive To-Do List Application built using HTML, CSS, and JavaScript.

This application helps users organize their daily tasks efficiently by allowing them to add, edit, delete, and manage tasks. It also uses LocalStorage to save tasks, so they remain available even after refreshing the browser.

## ✨ Features

- Add Tasks: Easily add new tasks to your to-do list.
- Edit Tasks: Update existing tasks whenever needed.
- Delete Tasks: Remove tasks that are no longer required.
- Mark as Completed: Mark tasks as completed or pending.
- Task Filtering: Filter tasks by All, Pending, and Completed.
- LocalStorage: Automatically save tasks in the browser.
- Responsive Design: Works on desktop and mobile devices.
- Simple Interface: Clean and user-friendly design.

## 💡 How It Works

1. Enter a task in the input field.
2. Click the Add button to add it to your list.
3. Use the Edit button to update an existing task.
4. Click the check button to mark a task as completed.
5. Use the Delete button to remove a task.
6. Select All, Pending, or Completed to filter your tasks.

All tasks are stored in browser LocalStorage, so your data remains saved after refreshing the page.
